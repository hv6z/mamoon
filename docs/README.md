## Sửa sơ đồ

Mở file `.mermaid` trên [mermaid.live](https://mermaid.live) hoặc VS Code (extension Mermaid), sửa rồi xuất lại PNG vào thư mục `png/`.
GitHub cũng hiển thị Mermaid nếu dán nội dung vào khối ```` ```mermaid ```` trong file `.md`.
